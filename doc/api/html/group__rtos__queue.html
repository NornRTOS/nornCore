The alternative to RTOS_QUEUE_INIT().

Parameters

storageitemSize * capacity bytes of storage. Must not be NULL and must stay valid for as long as the queue is used.
itemSizeBytes per item, 1 to 255.
capacityNumber of items the queue holds, 1 to 255.
Precondition
No task waits on the queue.
Warning
Checked: a NULL storage, an itemSize or a capacity of 0 panic with RTOS_PANIC_ARGUMENT.

Copies the oldest item out of the queue, waiting up to timeout ticks for one.

If a task is blocked in send because the queue was full, its item moves into the freed slot and that task may run before this function returns.

Parameters
pQThe queue.
pItemReceives the item, itemSize bytes.
timeoutTicks to wait; RTOS_NO_WAIT polls, RTOS_FOREVER waits for good.
Returns
true if an item was received, false on timeout.
Context
Task only; the idle task may only poll.

◆ rtos_queueSend()

bool rtos_queueSend ( rtos_queue_t * pQ,
const void * pItem,
rtos_tick_t timeout )

Copies an item into the queue, waiting up to timeout ticks for room.

If a task is blocked in receive, the item is copied straight into that task's buffer and the task may run before this function returns. A send that fails is counted in the queue's dropped field.

Parameters
pQThe queue.
pItemThe item, itemSize bytes. While the caller waits, the item is read at the moment a receiver frees a slot: it must not change until the call returns.
timeoutTicks to wait; RTOS_NO_WAIT polls, RTOS_FOREVER waits for good.
Returns
true if the item was queued, false if the queue stayed full.
Context
Task only; the idle task may only poll.
See also
rtos_queueSendFromIsr(), rtos_queueReceive()
