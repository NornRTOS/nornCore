◆ rtos_getCpuLoad()

uint8_t rtos_getCpuLoad ( void )

Returns the CPU load since the previous call.

The share of time not spent in the idle task, over the interval since the previous call (since rtos_start() for the first one). Needs RTOS_CFG_RUNTIME_STATS.

Returns
Load in percent, 0 to 100; 0 without RTOS_CFG_RUNTIME_STATS.
Context
Task only. Every call starts a new interval, so one task should own the readings.

◆ rtos_getStackFree()

size_t rtos_getStackFree ( uint8_t taskId)

Returns how many bytes at the bottom of a task's stack were never used.

The high water mark since the task was created: the fill pattern written by rtos_createTask() is counted from the bottom up.

Parameters
taskIdThe task, 0 to RTOS_CFG_NUM_TASKS (checked).
Returns
Untouched bytes; 0 for the idle task, for a task that was never created and without RTOS_CFG_STACK_CHECK.
Context
Task only.
Note
The scan reads the stack byte by byte with interrupts enabled; its time grows with the stack size.
See also
rtos_stackWarnHook(), RTOS_STACK_MIN

◆ rtos_getTaskRunTime()

rtos_runtime_t rtos_getTaskRunTime ( uint8_t taskId)

Returns the accumulated run time of a task.

Measured at every context switch, in counts of RTOS_RUNTIME_HZ; the running task's time includes the current slice. Needs RTOS_CFG_RUNTIME_STATS.

Parameters
taskIdThe task, 0 (idle) to RTOS_CFG_NUM_TASKS (checked).
Returns
The run time; 0 without RTOS_CFG_RUNTIME_STATS. The width of the count is the port's and it wraps.
Context
Task only.
See also
RTOS_RUNTIME_TO_MS(), rtos_getCpuLoad()

◆ rtos_getTimeUs()

uint32_t rtos_getTimeUs ( void )

Returns the microseconds since start.

Read from the port's free running time base (the tick timer's count on the AVR, 4 us steps at 16 MHz; the cycle counter on the ESP32), independent of the tick width. It wraps at 2^32 us, after 71.6 minutes: use differences.

Returns
Microseconds since rtos_start().
Context
Task, ISR body or timer callback.
See also
rtos_getTick()
