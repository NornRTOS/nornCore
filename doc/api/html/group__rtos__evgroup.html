◆ rtos_evgroupSet()

void rtos_evgroupSet ( rtos_evgroup_t * pG,
rtos_evt_t bits )

Sets bits and wakes every waiter whose condition is now met.

Waiters are served highest priority first. A waiter that asked for RTOS_WAIT_CLEAR takes its bits out of the group as it is woken, so a lower waiter no longer sees them. A woken task may run before this function returns.

Parameters
pGThe event group.
bitsThe bits to set.
Context
Task only. From an ISR body use rtos_evgroupSetFromIsr().
Note
With waiters present the call checks every task slot with interrupts disabled: its time grows with RTOS_CFG_NUM_TASKS.
See also
rtos_evgroupWait(), rtos_evgroupClear()

rtos_evt_t rtos_evgroupWait ( rtos_evgroup_t * pG,
rtos_evt_t mask,
uint8_t options,
rtos_tick_t timeout )

Waits until bits of mask are set in the group.

Parameters
pGThe event group.
maskThe bits to wait for. Must not be 0 (asserted).
optionsRTOS_WAIT_ANY or RTOS_WAIT_ALL, optionally ORed with RTOS_WAIT_CLEAR to take the satisfying bits out of the group atomically. Without RTOS_WAIT_CLEAR the bits stay set for other tasks.
timeoutTicks to wait; RTOS_NO_WAIT polls, RTOS_FOREVER waits for good.
Returns
The bits that satisfied the wait (with RTOS_WAIT_ALL: mask), 0 on timeout.
Context
Task only; the idle task may only poll.
See also
rtos_evgroupSet(), rtos_waitEvents()
