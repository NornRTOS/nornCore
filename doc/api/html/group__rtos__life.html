Definition rtos_types.h:77

Resets all kernel data; call once before any other kernel function.

Clears every task slot, the ready mask, the wake-up list and the tick count, and takes the panic record of the previous boot, if any, out of the memory that survives a reset (see rtos_getLastPanic()).

The macro passes RTOS_CONFIG_SIGNATURE, every layout changing option of the application's rtos_config.h folded into one number, to rtos_initChecked(). A kernel compiled with another configuration (stale objects, a library) stops at once instead of corrupting memory.

Precondition
Called from main(), before rtos_createTask() and rtos_start(), and only once.
Postcondition
No task exists; the tick count is 0.
Warning
A configuration mismatch panics with RTOS_PANIC_CONFIG (arg1: the application's signature, arg2: the kernel's).
See also
rtos_createTask(), rtos_start()

void rtos_createTask ( uint8_t prio,
rtos_taskFunc_t taskFunc,
void * arg,
uint8_t * stackArea,
size_t stackSize )

Creates and registers a new task.

Initializes the task at the given priority on a caller-provided stack. The task is ready at once and runs when the scheduler picks it, at the earliest at rtos_start().

Each priority has exactly one task slot, and the task id is the priority. The start of the stack area is moved up and its size rounded down to the stack alignment of the port (RTOS_PORT_STACK_ALIGN: 1 byte on the AVR, 16 on the ESP32), which may reduce the usable size.

Parameters
prioTask priority and id, 1 to RTOS_CFG_NUM_TASKS. A higher value is a higher priority. Must not be in use.
taskFuncEntry function of the task. Must not be NULL. It should never return; if it does, the task is terminated and never scheduled again.
argPassed to taskFunc unchanged. May be NULL.
stackAreaCaller-allocated stack memory. Must not be NULL and must stay valid for as long as the system runs (static storage, as a rule).
stackSizeSize of stackArea in bytes. After the alignment it must be at least RTOS_STACK_MIN; start from RTOS_STACK_DEFAULT and measure.
Precondition
rtos_init() has been called.
Called from main() before rtos_start(): creating a task while the scheduler runs is not supported.
Postcondition
The task is ready; it starts in taskFunc with arg.
Note
The kernel never allocates memory for a task: the caller owns the stack.
With RTOS_CFG_STACK_CHECK the whole stack area is filled with a pattern, which rtos_getStackFree() and the stack monitor read back.
Warning
Checked: prio out of range, a NULL taskFunc or stackArea, a slot in use or a stack below the minimum panic with RTOS_PANIC_ARGUMENT. There is no error return.
See also
rtos_taskFunc_t, RTOS_STACK_MIN, rtos_getStackFree()

◆ rtos_start()

void rtos_start ( void )

Starts the tick and the scheduler; never returns.

Creates the timer task when RTOS_CFG_TIMER_TASK_PRIO is above 0, starts the tick timer and switches to the highest priority ready task. The calling context becomes the idle task: it runs rtos_idleHook(), the watchdog and the stack monitor when they are configured, and sleeps (RTOS_CFG_IDLE_SLEEP) until the next interrupt.

Precondition
rtos_init() has been called and the tasks are created.
See also
rtos_init(), rtos_createTask(), rtos_idleHook()
