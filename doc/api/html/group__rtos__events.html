void rtos_postEvents ( uint8_t taskId,
rtos_evt_t events )

Posts events to a task.

The events are ORed into the task's pending events. If that satisfies the task's wait, it becomes ready and, if its priority is above the caller's, runs before this function returns.

Parameters
taskIdReceiving task, 1 to RTOS_CFG_NUM_TASKS (checked).
eventsThe events to post.
Context
Task only. From an ISR body use rtos_postEventsFromIsr().
See also
rtos_waitEvents(), rtos_broadcastEvents()

◆ rtos_waitEvents()

rtos_evt_t rtos_waitEvents ( rtos_evt_t mask,
uint8_t opt,
rtos_tick_t timeout )

Waits until events in mask are pending for the calling task.

Events posted earlier stay pending until a wait consumes them, so nothing is lost between two waits. The events that satisfy the wait are cleared and returned; pending events outside mask are kept.

Parameters
maskThe events to wait for. Must not be 0 (asserted).
optRTOS_WAIT_ANY: resume when any event of mask is pending. RTOS_WAIT_ALL: resume only when all of them are.
timeoutTicks to wait; RTOS_NO_WAIT polls, RTOS_FOREVER waits for good.
Returns
The consumed events (with RTOS_WAIT_ALL: mask), 0 on timeout.
Context
Task only; the idle task may only poll.
See also
rtos_postEvents(), rtos_postEventsFromIsr(), rtos_evgroupWait()
