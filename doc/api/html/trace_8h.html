Detailed Description

Ring buffer recorder for the kernel trace hook (RTOS_CFG_TRACE).

The application implements rtos_traceHook by calling trace_record, and prints the buffer with trace_dump when something went wrong, for example from rtos_panicHook. Entries carry the run time counter (RTOS_RUNTIME_HZ) as time stamp. TRACE_DEPTH entries are kept; the oldest are overwritten.
