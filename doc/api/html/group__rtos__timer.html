◆ rtos_timerStart()

void rtos_timerStart ( rtos_timer_t * pT,
rtos_tick_t delay,
rtos_tick_t period )

Arms the timer; restarts it if it is already active.

The first expiry is on the delay-th tick from now. Since part of the current tick period is already gone, that is after delay - 1 to delay tick periods. A delay of 0 means the next tick, as 1 does, and never the current one, so a callback may restart its own timer with 0. After that the timer expires every period ticks exactly, counted from the previous expiry, so it does not drift.

Parameters
pTThe timer, prepared with rtos_timerInit() (checked).
delayTicks to the first expiry, 0 to RTOS_MAX_TIMEOUT (checked).
periodTicks between later expiries, 0 for a one shot timer; at most RTOS_MAX_TIMEOUT (checked).
Context
Task, ISR body or timer callback.
Note
The active timers are kept sorted by expiry: the time this call spends with interrupts disabled grows with the number of active timers.
See also
rtos_timerStop(), rtos_timerRemaining()

◆ rtos_timerStop()

void rtos_timerStop ( rtos_timer_t * pT)

Disarms the timer.

Nothing happens if it is not active. With a timer task (RTOS_CFG_TIMER_TASK_PRIO above 0), an expiry that is still waiting for the timer task is dropped as well; a callback that is already running finishes.

Parameters
pTThe timer.
Context
Task, ISR body or timer callback.
