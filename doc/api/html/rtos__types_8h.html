Detailed Description

Kernel scalar types derived from the application configuration.

Included by rtos.h and by the port layer, so it must not depend on either.

Every option that changes the kernel's data layout or behaviour, folded into one number.

rtos_init passes the application's value to the kernel, which compares it with its own: a kernel built from another configuration (stale objects, a library) is caught at start (RTOS_PANIC_CONFIG) instead of corrupting memory.
