◆ rtos_resume()

void rtos_resume ( uint8_t taskId)

Lets a suspended task run again.

The task becomes ready if it is not still blocked, and may run before this function returns. Nothing happens if the task is not suspended.

Parameters
taskIdThe task, 1 to RTOS_CFG_NUM_TASKS (checked).
Context
Task only. From an ISR body use rtos_resumeFromIsr().

◆ rtos_suspend()

void rtos_suspend ( uint8_t taskId)

Keeps a task from running until rtos_resume().

A blocked task stays in its wait. A wake up that arrives meanwhile (an event, a token, a timeout) is kept and takes effect at the resume. Suspending a suspended task changes nothing; there is no nesting count. A task may suspend itself; it stops at once.

Parameters
taskIdThe task, 1 to RTOS_CFG_NUM_TASKS (checked); not the idle task.
Context
Task only.
Warning
A suspended task keeps the mutexes it holds.
