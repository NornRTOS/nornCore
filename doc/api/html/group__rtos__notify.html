Detailed Description

One 16 bit value per task: the cheapest signal, no object needed (RTOS_CFG_NOTIFY).

void rtos_notify ( uint8_t taskId,
uint16_t value,
uint8_t op )

Updates a task's notification value and wakes the task if it waits for it.

The task is woken if it waits in rtos_notifyWait(), or in rtos_notifyTake() and the value is now non-zero; it may run before this function returns.

Parameters
taskIdReceiving task, 1 to RTOS_CFG_NUM_TASKS (checked).
valueOperand of op; ignored by RTOS_NOTIFY_INC.
opRTOS_NOTIFY_SET: replace the value. RTOS_NOTIFY_OR: OR value in (flags). RTOS_NOTIFY_INC: add one, saturating at 0xFFFF (counting).
Context
Task only. From an ISR body use rtos_notifyFromIsr().
See also
rtos_notifyWait(), rtos_notifyTake()

Updates a task's notification value from an ISR body.

As rtos_notify(); a switch to the woken task happens at the end of the ISR.

Parameters

valueOperand of op; ignored by RTOS_NOTIFY_INC.
opRTOS_NOTIFY_SET, RTOS_NOTIFY_OR or RTOS_NOTIFY_INC.
Context
RTOS_ISR body or timer callback in the tick.

◆ rtos_notifyTake()

bool rtos_notifyTake ( rtos_tick_t timeout)

Waits until the notification value is non-zero, then decrements it by one.

With RTOS_NOTIFY_INC on the sending side this is a counting semaphore without an object.

Parameters
timeoutTicks to wait; RTOS_NO_WAIT polls, RTOS_FOREVER waits for good.
Returns
true if the value was decremented, false on timeout.
Context
Task only; the idle task may only poll.
Note
rtos_notifyWait() and rtos_notifyTake() share the one value; a task should use one style.
See also
rtos_notify(), rtos_notifyWait()

bool rtos_notifyWait ( uint16_t * pValue,
rtos_tick_t timeout )

Waits for a notification and takes the whole value.

Returns as soon as any notification has arrived since the last successful wait, even one that set the value to 0. The value is then reset to 0.

Parameters
pValueReceives the value. May be NULL.
timeoutTicks to wait; RTOS_NO_WAIT polls, RTOS_FOREVER waits for good.
Returns
true if a notification was taken, false on timeout.
Context
Task only; the idle task may only poll.
