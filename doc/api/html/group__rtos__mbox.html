Takes the item out of the mailbox, waiting up to timeout ticks for one.

Parameters

pItemReceives the item, itemSize bytes.
timeoutTicks to wait; RTOS_NO_WAIT polls, RTOS_FOREVER waits for good.
Returns

◆ rtos_mboxPost()

bool rtos_mboxPost ( rtos_mbox_t * pMb,
const void * pItem )

Puts an item in the mailbox, replacing an unread one; never blocks.

If a task is blocked in fetch, the item is copied straight into that task's buffer (the mailbox stays empty) and the task may run before this function returns. A replaced item is counted in the mailbox's overwrites field.

Parameters
pMbThe mailbox.
pItemThe item, itemSize bytes.
Returns
true if an unread item was overwritten.
Context
Task only. From an ISR body use rtos_mboxPostFromIsr().
See also
rtos_mboxFetch()
