Detailed Description

Minimal polling driver for the console UART (UART0), for logging from applications and test cases.

Implemented per architecture in hal/<arch>/uart.c. Not interrupt driven: a call blocks until the byte is in the transmit register, so it is cheap for short messages and simple to use from any task. Shared use from several tasks needs a mutex around whole messages.
