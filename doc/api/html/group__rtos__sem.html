Detailed Description

Token counters with direct hand-over to the highest priority waiter.

◆ rtos_semGive()

void rtos_semGive ( rtos_sem_t * pSem)

Gives one token.

If tasks wait, the highest priority waiter gets the token directly (the count does not change) and may run before this function returns. Otherwise the count goes up, or, at the limit, the give is dropped and counted as lost.

Parameters
pSemThe semaphore.
Context
Task only. From an ISR body use rtos_semGiveFromIsr().
See also
rtos_semTake()

void rtos_semInitMax ( rtos_sem_t * pSem,
uint8_t initialCount,
uint8_t maxCount )

Initializes a semaphore with an upper limit at run time.

A give that finds the count at maxCount is dropped and counted in the semaphore's lost field. maxCount 1 makes a binary semaphore.

Parameters
pSemThe semaphore.
initialCountTokens available at the start, at most maxCount (asserted).
maxCountUpper limit of the count, at least 1 (asserted).
Precondition
No task waits on the semaphore.
See also
RTOS_SEM_INIT_MAX(), RTOS_SEM_INIT_BINARY()
