◆ rtos_getLastPanic()

bool rtos_getLastPanic ( rtos_panicInfo_t * pInfo)

Reads the panic record left before the last reset, if any.

rtos_init() takes the record out of the memory that survives a reset, so each record is reported in one boot only. A power cycle loses it.

Parameters
pInfoReceives the record. May be NULL to only ask whether there is one.
Returns
true if the previous run ended in a panic.
Precondition
rtos_init() has been called.
See also
rtos_panic(), rtos_getResetCause()

◆ rtos_panic()

void rtos_panic ( uint8_t reason,
uint32_t arg1,
uint32_t arg2 )

Stops the system.

Disables interrupts, records the reason in memory that survives a reset, calls rtos_panicHook() and then halts (RTOS_CFG_PANIC_ACTION 0) or resets (1).

Parameters
reasonA rtos_panicReason_t; applications use RTOS_PANIC_APPLICATION.
arg1First argument, stored in the record.
arg2Second argument, stored in the record.
Context
Any: task, ISR body, timer callback, hook.
See also
rtos_getLastPanic(), rtos_panicHook()
