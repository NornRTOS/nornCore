◆ rtos_free()

void rtos_free ( void * p)

Returns a block from rtos_malloc(); NULL is ignored.

The block merges with free neighbours on both sides.

Parameters
pThe block, exactly as rtos_malloc() returned it, or NULL.
Context
Task only.
Warning
Checked: a pointer outside the heap or a block that is already free panics with RTOS_PANIC_ARGUMENT. A pointer into the middle of a block is not detected and corrupts the heap.
See also
rtos_malloc()

◆ rtos_heapInit()

void rtos_heapInit ( void * area,
size_t size )

Gives the allocator its memory.

The start of the area is aligned up to 2 * sizeof(void *) and the size rounded down.

Parameters
areaThe memory to allocate from. Must not be NULL and must stay valid for as long as the heap is used.
sizeSize of area in bytes; at least a few dozen (four minimum blocks, checked).
Precondition
Called once, before the first rtos_malloc(). A second call forgets every block.
Warning
Checked: a NULL area or a too small size panic with RTOS_PANIC_ARGUMENT.
See also
rtos_malloc(), rtos_heapStats()

◆ rtos_malloc()

void * rtos_malloc ( size_t size)

Allocates size bytes.

First fit over the free list. The block is aligned to 2 * sizeof(void *) and costs a few bytes of header and boundary tag on top of size. A failed allocation is counted in the statistics.

Parameters
sizeBytes wanted.
Returns
The block, or NULL if no free block is large enough.
Context
Task only.
Note
The search runs with interrupts disabled and its time grows with the number of free blocks. For a bounded worst case use a memory pool (rtos_poolAlloc()).
Warning
Checked: a call before rtos_heapInit() panics with RTOS_PANIC_ARGUMENT.
See also
rtos_free()
