◆ rtos_assertFailed()

void rtos_assertFailed ( const char * file,
uint16_t line )

Called when an assertion (RTOS_ASSERT) fails.

The weak default stores file and line in the panic record and calls rtos_panic() with RTOS_PANIC_ASSERT.

Parameters
fileSource file of the assertion; on the AVR a string in program memory.
lineSource line of the assertion.
Warning
An override must not return either: the kernel is in an undefined state, and the compiler relies on it.

◆ rtos_idleHook()

void rtos_idleHook ( void )

Called in every iteration of the idle loop.

Used when RTOS_CFG_IDLE_HOOK is not defined (a binary kernel cannot take a macro). The weak default does nothing; an application overrides it to drive sensors, feed a console or sleep deeper.

Context
The idle task; must not block.

Called by rtos_panic() before the halt or reset.

Parameters

◆ rtos_stackWarnHook()

void rtos_stackWarnHook ( uint8_t task,
size_t stackFree )

Called once per task when its unused stack drops below RTOS_PORT_STACK_WARN.

The stack monitor (RTOS_CFG_STACK_WARN with RTOS_CFG_STACK_CHECK) reads the high water mark of one task per idle loop. The weak default does nothing; an application prints or logs here.

Parameters
taskThe task whose margin is gone.
stackFreeIts untouched stack bytes, as rtos_getStackFree() reports them.
Context
The idle task; must not block.
