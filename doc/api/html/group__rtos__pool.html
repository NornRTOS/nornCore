◆ rtos_poolFree()

void rtos_poolFree ( rtos_pool_t * pPool,
void * pBlock )

Returns a block to its pool.

If a task waits for a block, it gets this one directly and may run before this function returns.

Parameters
pPoolThe pool the block came from.
pBlockThe block, as returned by rtos_poolAlloc() or rtos_poolAllocFromIsr().
Context
Task only. From an ISR body use rtos_poolFreeFromIsr().
Warning
Checked: a pointer outside the pool or not at the start of a block panics with RTOS_PANIC_ARGUMENT. A block freed twice is caught only when the pool would hold more free blocks than it has; otherwise it corrupts the free list.
See also
rtos_poolAlloc()

◆ rtos_poolInit()

void rtos_poolInit ( rtos_pool_t * pPool,
uint8_t * storage,
uint16_t blockSize,
uint8_t numBlocks )

Builds the free list of a pool over the given storage.

Also required after RTOS_POOL_INIT(). Any alignment of the storage and any block size from sizeof(void *) up work. A block is returned at the alignment of its offset in the storage, so storage meant for aligned objects must be aligned itself and have a block size that is a multiple of that alignment.

Parameters
pPoolThe pool.
storageblockSize * numBlocks bytes. Must not be NULL and must stay valid for as long as the pool is used.
blockSizeBytes per block, at least sizeof(void *).
numBlocksNumber of blocks, 1 to 255.
Precondition
No block of the pool is in use and no task waits on it.
Warning
Checked: a NULL storage, a blockSize below sizeof(void *) or a numBlocks of 0 panic with RTOS_PANIC_ARGUMENT.
